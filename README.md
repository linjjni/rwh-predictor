# RwhPredictor app

屋面雨水回收（RWH）经济性预测 App。运行时仅依赖 `flet`，随机森林推理用标准库完成。

首次运行或模型更新后，先在电脑端构建资源：

```bash
python build_assets.py
```

## Run the app

### uv

Run as a desktop app:

```bash
uv run flet run
```

Run as a web app:

```bash
uv run flet run --web
```

For more details on running the app, refer to the [Getting Started Guide](https://flet.dev/docs/).
